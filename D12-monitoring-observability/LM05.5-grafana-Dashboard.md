# Part 23 — Create Grafana NGINX Dashboard

Go to:

```text
Grafana
   ↓
Dashboards
   ↓
New Dashboard
```

Create:

```text
NGINX Observability Dashboard
```

I recommend these panels.

---


# Part 24 — Create NGINX Log Panel in Grafana

Create another panel.

Select:

```text
Loki
```

Query:

```logql
{namespace="nginx-observability"}
```

Title:

```text
NGINX Application Logs
```

Visualization:

```text
Logs
```

Now the dashboard combines:

```text
+-----------------------+
| Active Connections    |
+-----------------------+

+-----------------------+
| Requests / Second     |
+-----------------------+

+-----------------------+
| Total Requests        |
+-----------------------+

+-----------------------+
| NGINX Logs            |
+-----------------------+
```

# Part 25 — Create a 404 Log Panel

Use:

```logql
{namespace="nginx-observability"} |= "404"
```

Title:

```text
NGINX 404 Errors
```

Generate errors:

```bash
for i in {1..20}
do
  curl -s http://$NGINX_IP/not-found-$i > /dev/null
done
```

The dashboard should now show the 404 requests.

---

# Part 26 — Create a 404 Rate Panel

This is more advanced and useful for teaching.

If your Loki version supports metric queries, use:

```logql
sum(
  count_over_time(
    {namespace="nginx-observability"} |= "404" [5m]
  )
)
```

Title:

```text
NGINX 404 Errors - Last 5 Minutes
```

Visualization:

```text
Time series
```
