# Part 34 — Final Observability Test

Students should now perform the following.

## Test 1 — Normal traffic

```bash
curl http://$NGINX_IP/
```

Verify:

```text
HTTP 200
```

Check:

```text
Loki
Prometheus
Grafana
```

---

## Test 2 — 404 traffic

```bash
curl http://$NGINX_IP/test
```

Verify:

```text
404 log
```

in Loki.

---

## Test 3 — Generate load

```bash
for i in {1..500}
do
  curl -s http://$NGINX_IP/ > /dev/null
done
```

Verify:

```text
Request rate ↑
```

in Prometheus/Grafana.

---

## Test 4 — Generate 404 storm

```bash
for i in {1..200}
do
  curl -s http://$NGINX_IP/not-found-$i > /dev/null
done
```

Verify:

```text
404 logs ↑
```

and:

```text
NGINX Too Many 404 Errors
```

fires.

---

## Test 5 — Stop NGINX

```bash
kubectl scale deployment nginx \
  -n nginx-observability \
  --replicas=0
```

Verify:

```text
NGINX Metrics Target Down
```

fires.

Recover:

```bash
kubectl scale deployment nginx \
  -n nginx-observability \
  --replicas=2
```
