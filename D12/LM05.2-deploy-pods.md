# Part 4 — Create NGINX Namespace

Create a dedicated namespace.

```bash
kubectl create namespace nginx-observability
```

Verify:

```bash
kubectl get ns nginx-observability
```

---

# Part 5 — Deploy NGINX

Create:

```bash
nano nginx.yaml
```

Use:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx
  namespace: nginx-observability
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.27
          ports:
            - name: http
              containerPort: 80
          resources:
            requests:
              cpu: 100m
              memory: 64Mi
            limits:
              cpu: 500m
              memory: 256Mi
          volumeMounts:
            - name: nginx-config
              mountPath: /etc/nginx/conf.d
      volumes:
        - name: nginx-config
          configMap:
            name: nginx-config

---
apiVersion: v1
kind: ConfigMap
metadata:
  name: nginx-config
  namespace: nginx-observability
data:
  default.conf: |
    server {
        listen 80;

        location / {
            root /usr/share/nginx/html;
            index index.html;
        }

        location /health {
            access_log off;
            return 200 "OK\n";
        }
    }
```

Apply:

```bash
kubectl apply -f nginx.yaml
```

Check:

```bash
kubectl get pods -n nginx-observability
```

Expected:

```text
nginx-xxxxx   1/1   Running
nginx-yyyyy   1/1   Running
```

# Part 6 — Expose NGINX Through MetalLB

Create:

```bash
nano nginx-service.yaml
```

```yaml
apiVersion: v1
kind: Service
metadata:
  name: nginx
  namespace: nginx-observability
spec:
  type: LoadBalancer
  selector:
    app: nginx
  ports:
    - name: http
      port: 80
      targetPort: 80
```

Apply:

```bash
kubectl apply -f nginx-service.yaml
```

Check:

```bash
kubectl get svc -n nginx-observability
```

You should eventually see:

```text
NAME    TYPE           CLUSTER-IP    EXTERNAL-IP
nginx   LoadBalancer   10.x.x.x      192.168.230.xxx
```

The `EXTERNAL-IP` is supplied by MetalLB.

# Part 7 — Test NGINX

Set the IP:

```bash
export NGINX_IP=<METALLB-IP>
```

For example:

```bash
export NGINX_IP=192.168.230.240
```

Test:

```bash
curl http://$NGINX_IP
```

You should receive the standard NGINX page.

Test health:

```bash
curl http://$NGINX_IP/health
```

Expected:

```text
OK
```
