# Task 9A

# Trigger the Alert

Our Nginx server doesn't naturally consume much CPU from HTTP requests alone, so we'll create a dedicated CPU stress workload.

## Step 1

Create a CPU-intensive pod:

```bash
kubectl run cpu-stress \
--image=busybox \
-n demo \
--restart=Never \
-- /bin/sh -c "while true; do sha256sum /dev/zero; done"
```

Verify:

```bash
kubectl get pod -n demo
```

---

## Step 2

Open Grafana and monitor:

* CPU Usage panel
* Alert Rules

You should observe:

```
Normal

↓

Pending

↓

Firing
```

Depending on evaluation intervals, this may take 2–3 minutes.

---

## Step 3

Inspect the alert details:

* Alert Name
* Current CPU Value
* Evaluation Time
* Namespace
* Trigger Status

---

## Step 4

Delete the stress pod to stop the load:

```bash
kubectl delete pod cpu-stress -n demo
```

After a short period, the alert should transition back through:

```
Firing

↓

Recovering

↓

Normal
```
