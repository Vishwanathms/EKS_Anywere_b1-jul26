# Part 8 — Generate NGINX Traffic

This is important because **metrics and logs become much more interesting when traffic is generated**.

Run:

```bash
while true
do
  curl -s http://$NGINX_IP/ > /dev/null
  sleep 1
done
```

Leave this running.

Open another terminal.

Generate health requests:

```bash
for i in {1..100}
do
  curl -s http://$NGINX_IP/health
done
```

Generate invalid URLs:

```bash
for i in {1..50}
do
  curl -s http://$NGINX_IP/does-not-exist
done
```

Now you have:

```text
200 requests
404 requests
continuous traffic
```

This will be useful later for Grafana and alerts.

# Part 9 — Check NGINX Logs Directly

First find the pods:

```bash
kubectl get pods -n nginx-observability
```

Then:

```bash
kubectl logs -n nginx-observability <NGINX-POD>
```

You should see something similar to:

```text
10.244.x.x - - [10/Aug/2026:10:00:00 +0000] "GET / HTTP/1.1" 200 ...
```

Generate another request:

```bash
curl http://$NGINX_IP/test
```

Then:

```bash
kubectl logs -n nginx-observability <NGINX-POD> --tail=10
```

You should see:

```text
"GET /test HTTP/1.1" 404
```

This proves:

```text
Client
   |
   v
NGINX
   |
   v
stdout
   |
   v
Kubernetes container logs
```

# Part 10 — Verify Loki Is Receiving NGINX Logs

Now go to Grafana.

Open:

```text
Explore
```

Select:

```text
Loki
```

Start with:

```logql
{namespace="nginx-observability"}
```

Depending on your collector's labels, this may work directly.

If not, discover the labels.

In Grafana Explore, run:

```logql
{}
```

Then inspect the available labels.

You may find labels such as:

```text
namespace
pod
container
app
job
```

Try:

```logql
{app="nginx"}
```

or:

```logql
{container="nginx"}
```

or:

```logql
{namespace="nginx-observability", container="nginx"}
```

# Part 11 — Search Only NGINX 404 Logs

Once the correct labels are identified:

```logql
{namespace="nginx-observability"} |= "404"
```

Generate:

```bash
curl http://$NGINX_IP/not-found
```

Then refresh Explore.

You should see:

```text
GET /not-found HTTP/1.1" 404
```

This is the first important observability validation:

```text
NGINX
  |
  | logs
  v
Log Collector
  |
  v
Loki
  |
  v
Grafana Explore
```
