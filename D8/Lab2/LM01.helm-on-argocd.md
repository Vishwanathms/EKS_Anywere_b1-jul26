# Lab 2 – Deploy Helm Chart using ArgoCD on EKS Anywhere

## Objective

In this lab, students will deploy a Helm chart stored in GitHub using ArgoCD.

Instead of applying Kubernetes YAML files directly, ArgoCD will:

```
Git Repository
      │
      ▼
Helm Chart
      │
      ▼
ArgoCD
      │
      ▼
helm template
      │
      ▼
Kubernetes Manifests
      │
      ▼
EKS Anywhere Cluster
```

This is the deployment model followed in most production GitOps environments.

# Test GitOps

Modify `values.yaml`:

```yaml
replicas: 3

environment: PROD

color: green

version: v2.0
```

Commit and push:

```bash
git add .
git commit -m "Updated Helm values"
git push origin main
```

ArgoCD detects the change automatically. In the application view, you can watch the sequence:

```
OutOfSync
      │
      ▼
Syncing
      │
      ▼
Healthy
      │
      ▼
Synced
```

Verify the replica count:

```bash
kubectl get deployment -n gitops-helm
```

Or:

```bash
kubectl get pods -n gitops-helm
```

You should now see **3 Pods** instead of **2**, demonstrating the complete GitOps flow:

```
Developer
    │
    ▼
Edit values.yaml
    │
    ▼
Git Commit
    │
    ▼
Git Push
    │
    ▼
GitHub Repository
    │
    ▼
ArgoCD Polls Repository
    │
    ▼
Detects Helm Chart
    │
    ▼
Runs helm template
    │
    ▼
Applies Rendered Manifests
    │
    ▼
EKS Anywhere Cluster Updated
```
