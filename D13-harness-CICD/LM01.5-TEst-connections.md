
# PART 21 — Create GitHub Connector

In Harness:

```text
Project
   |
   +-- Settings
       |
       +-- Connectors
              |
              +-- New Connector
```

Select:

```text
GitHub
```

Use:

```text
Connector Name:

github-eks-training
```

Choose the appropriate authentication method.

For classroom training, HTTPS + GitHub PAT is straightforward.

The PAT should have only the permissions required to read the repository.

```text

```

button.

Click it.

Expected:

```text

```

# PART 23 — Create Kubernetes Connector

This is an important part of the lab.

Go to:

```text
Project
   |
   +-- Settings
       |
       +-- Connectors
              |
              +-- New Connector
```

Select:

```text
Kubernetes
```

Use:

```text
Name:

eks-anywhere-kubernetes
```

For authentication, use the Kubernetes authentication method supported by your Harness configuration.

The key concept is:

```text
Harness
   |
   +-- Kubernetes Connector
             |
             +-- Delegate
                    |
                    +-- Kubernetes API
```

For a Kubernetes connector, Harness uses the Delegate to reach the target cluster rather than requiring the Harness SaaS control plane to directly access your private Kubernetes API.

---

# PART 24 — Delegate Selection

When configuring the Kubernetes connector, select:

```text
Connect through a Delegate
```

Then specify your Delegate.

For example:

```text
Delegate Selector:

eks-anywhere
```

or the tag you assigned.

This is the critical connection:

```text
Harness Kubernetes Connector
            |
            v
   Delegate Selector
            |
            v
EKS Anywhere Delegate
            |
            v
    Kubernetes API
```
