PART 19 — Create Kubernetes Test Application

Before building the Harness pipeline, create a simple NGINX application.

Create:

mkdir harness-nginx
cd harness-nginx

Create:

deployment.yaml

Content:

apiVersion: apps/v1
kind: Deployment
metadata:
  name: harness-nginx
  namespace: harness-demo
spec:
  replicas: 2
  selector:
    matchLabels:
      app: harness-nginx
  template:
    metadata:
      labels:
        app: harness-nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.27
          ports:
            - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: harness-nginx
  namespace: harness-demo
spec:
  type: ClusterIP
  selector:
    app: harness-nginx
  ports:
    - port: 80
      targetPort: 80

Create namespace:

kubectl create namespace harness-demo

For the first test:

kubectl apply -f deployment.yaml

Verify:

kubectl get pods -n harness-demo

Expected:

harness-nginx-xxxxx   Running
harness-nginx-yyyyy   Running
