# PART 19 — Create Kubernetes Test Application

Before building the Harness pipeline, create a simple NGINX application.

Create:

```bash
mkdir harness-nginx
cd harness-nginx
```

Create:

```bash
deployment.yaml
```

Content:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: harness-nginx
  namespace: harness-demo
spec:
  replicas: 2
  selector:
    matchLabels:
      app: harness-nginx
  template:
    metadata:
      labels:
        app: harness-nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.27
          ports:
            - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: harness-nginx
  namespace: harness-demo
spec:
  type: ClusterIP
  selector:
    app: harness-nginx
  ports:
    - port: 80
      targetPort: 80
```

Create namespace:

```bash
kubectl create namespace harness-demo
```

For the first test:

```bash
kubectl apply -f deployment.yaml
```

Verify:

```bash
kubectl get pods -n harness-demo
```

Expected:

```text
harness-nginx-xxxxx   Running
harness-nginx-yyyyy   Running
```


