
# PART 1 — Create Harness SaaS Account

## Step 1 — Open Harness

Open:

[Harness SaaS](https://app.harness.io/?utm_source=chatgpt.com)

Create/sign into your Harness account.

For classroom training, I recommend:

```text
Harness Account
       |
       +-- Organization
              |
              +-- EKS-Anywhere-Training
                       |
                       +-- Project
                              |
                              +-- EKS-Anywhere-CICD
```

This gives students a clean hierarchy.

Organization:

# PART 3 — Understand the Harness Hierarchy

Explain this to students before continuing.

```text
Harness Account
      |
      +--- Organization
              |
              +--- Project
                      |
                      +--- Service
                      |
                      +--- Environment
                      |
                      +--- Connector
                      |
                      +--- Pipeline
```

A simple analogy:

| Harness      | Kubernetes analogy         |
| ------------ | -------------------------- |
| Account      | Cluster/platform boundary  |
| Organization | Team/business unit         |
| Project      | Application/team workspace |
| Service      | Application                |
| Environment  | Deployment target          |
| Pipeline     | Automation workflow        |
| Delegate     | Worker/agent               |
| Connector    | Integration/authentication |
| Secret       | Sensitive configuration    |

# PART 4 — Create Harness Delegate Token

This is an important step.

Go to:

```text
Account Settings
    |
    +-- Account Resources
           |
           +-- Delegates
```

Select:

```text
Tokens
   |
   +-- New Token
```

Create:

```text
Name:

eks-anywhere-delegate-token
```

Click:

```text
Apply
```

**Copy the token immediately.**

Do not put the token into Git.

Harness documentation currently recommends creating the Delegate token under Account Settings → Account Resources → Delegates → Tokens. ([Harness][1])

---

# PART 5 — Get Harness Account ID

Go to:

```text
Account Settings
     |
     +-- Account Details / Overview
```

You need:

```text
ACCOUNT_ID
```

For example:

```text
ACCOUNT_ID=xxxxxxxxxxxxxxxx
```

Do **not** use the example value above.

Get the real value from your Harness account.

Harness also documents that the account ID is present in the Harness URL. ([Harness][1])

---

# PART 6 — Determine Harness Manager Endpoint

For normal Harness SaaS production accounts, the Manager endpoint is typically:

```text
https://app.harness.io
```

Harness currently documents different endpoints depending on the SaaS cluster location, so students should use the endpoint shown by the Delegate installation wizard rather than blindly hard-coding one. ([Harness][1])

For this lab, assume:

```text
MANAGER_ENDPOINT=https://app.harness.io
```
