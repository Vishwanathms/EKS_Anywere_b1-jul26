# Lab: Import EKS Anywhere Cluster into Rafay SaaS

## 1. Lab Objective

In this lab, you will:

* Log in to the Rafay SaaS console.
* Verify your Rafay project and permissions.
* Verify connectivity from the private EKS Anywhere cluster to Rafay SaaS.
* Create an **Imported Cluster** entry in your Rafay project.
* Download the unique Rafay bootstrap YAML.
* Apply the bootstrap YAML to the EKS Anywhere cluster.
* Verify the Rafay management components.
* Verify that the cluster becomes available in the Rafay project.
* Confirm that the cluster is synchronized with Rafay.

### Expected Result

At the end of the lab, you should have:

```text
Rafay SaaS
    |
    +-- Your Project
          |
          +-- EKS Anywhere Cluster
                |
                +-- Rafay Management Operator
                |
                +-- Rafay Connector
                |
                +-- Rafay Relay Agent
```

Your EKS Anywhere cluster remains **private**. You do not need to expose the Kubernetes API to the Internet.

# 2. Lab Architecture

Your lab environment looks like this:

```text
                         Internet
                            |
                            |
                    +----------------+
                    |   Rafay SaaS   |
                    | console.rafay  |
                    +--------+-------+
                             |
                             |
                       HTTPS / TCP 443
                             |
                             |
                        +----+----+
                        | pfSense |
                        +----+----+
                             |
                     Private Network
                             |
                +------------+------------+
                |                         |
        +-------+-------+         +-------+-------+
        | EKS-A Control |         | EKS-A Worker |
        |     Plane     |         |     Node     |
        +---------------+         +-------------+
                |
                |
        Rafay Management Pods
          rafay-system namespace
```

### Important

The EKS Anywhere cluster does **not** require an inbound Internet connection.

Rafay's Kubernetes management operator establishes a long-running outbound TLS/mTLS control channel to the Rafay SaaS controller using **TCP 443**. Rafay's documentation specifically states that no inbound external firewall ports are required for this control-plane communication.
