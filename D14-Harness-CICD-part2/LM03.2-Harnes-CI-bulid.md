# PART 6 — CONFIGURE HARNESS CI BUILD INFRASTRUCTURE

## 17. Create a CI Pipeline

Go to:

```text
Harness
 → Project
 → CI
 → Pipelines
 → Create Pipeline
```

Name:

```text
python-redis-ci
```

Add:

```text
Build stage
```

Harness CI Build stages can be configured from the Overview, Infrastructure, Execution and Advanced sections. ([Harness][3])

---

# 18. Configure Build Infrastructure

Open:

```text
Build Stage
 → Infrastructure
```

Select:

```text
Infrastructure:
Local
```

Operating system:

```text
Linux
```

Architecture:

```text
AMD64
```

This is the key point:

```text
Harness SaaS
       |
       v
Linux CI VM
       |
       +--> Delegate
       |
       +--> Docker Runner
```

The current Harness local runner documentation shows selecting **Local** infrastructure and Linux/AMD64 in the CI stage. ([Harness][1])

---

# 19. Pipeline YAML Infrastructure

In YAML, the CI stage should contain the equivalent runtime configuration:

```yaml
platform:
  os: Linux
  arch: Amd64

runtime:
  type: Docker
  spec: {}
```

Harness's current local runner documentation shows this pattern for Linux Docker Runner infrastructure. ([Harness][1])

# PART 8 — PYTHON BUILD

## 22. Add Python Build Step

Add:

```text
Run
```

Name:

```text
Build Python Application
```

Command:

```bash
python3 --version

pip3 --version

pip3 install -r app/requirements.txt

python3 -m compileall app/
```

This confirms:

```text
Source code
    ↓
Python build
    ↓
Successful application preparation
```

---

# 23. Add a Simple Test

Add another Run step:

```text
Run Python Test
```

For a simple demonstration:

```bash
python3 -m compileall app/
```

If the application already has tests:

```bash
pytest
```

Use the application's existing test command instead.

# PART 9 — DOCKER BUILD AND PUSH

## 24. Add Docker Connector

In Harness:

```text
Project
 → Settings
 → Connectors
 → New Connector
```

Select Docker Registry.

Name:

```text
dockerhub-python-redis
```

Configure:

```text
Registry:
Docker Hub

Username:
<dockerhub-user>

Password:
<Docker Hub Access Token>
```

Test:

```text
Test Connection
```

Expected:

```text
Connection Successful
```

---

# 25. Add Docker Build and Push Step

Inside the CI stage:

```text
Add Step
 → Build
 → Build and Push an Image to Docker Registry
```

Configure:

```text
Connector:
dockerhub-python-redis
```

Repository:

```text
<DOCKERHUB_USERNAME>/python-redis-app
```

Dockerfile:

```text
Dockerfile
```

Build context:

```text
.
```

Tag:

```text
<+pipeline.sequenceId>
```

Harness's current Docker Build and Push step supports Docker Hub and Linux execution and can use Buildx caching or Kaniko depending on the configured build infrastructure/options. ([Harness][4])
